## 🔥 Sobre o Projeto
Este projeto implementa um sistema CRUD (Create, Read, Update, Delete) utilizando **Express** e **MongoDB**, permitindo o cadastro, listagem, edição e exclusão de registros em banco de dados.

O foco é demonstrar:
- Estruturação de rotas REST
- Conexão com banco relacional
- Manipulação de dados persistidos
- Organização de camadas no backend

---

## 🚀 Tecnologias Utilizadas

| Tecnologia | Descrição |
|-----------|-----------|
| **Node.js** | Ambiente de execução JavaScript |
| **Express** | Framework para criação das rotas e servidor |
| **MySQL** | Banco de dados relacional para persistência |
| **Postman** | Teste e validação das requisições |
| **Git & GitHub** | Versionamento de código |
